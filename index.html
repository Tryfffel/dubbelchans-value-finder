🧮 Hur Value-beräkningen fungerar

Poisson-modellen är ett klassiskt statistiskt verktyg för att förutsäga fotbollsresultat. Appen beräknar förväntade mål (λ) för varje lag:

λ_hemma = (lag_hemma_mål_gjorda / snitt) × (lag_borta_mål_insläppta / snitt) × liga_snitt × formfaktor
λ_borta = (lag_borta_mål_gjorda / snitt) × (lag_hemma_mål_insläppta / snitt) × liga_snitt × formfaktor

Sedan beräknas sannolikheten för varje möjligt målscenario via Poisson-formeln och summeras för att ge P(hemma), P(oavgjort), P(borta).

Dubbelchans kombineras sedan: P(1X) = P(hemma) + P(oavgjort) osv.

Value % = ((marknadens odds / riktigt odds) - 1) × 100

Om Value % är positivt har spelbolaget satt för höga odds jämfört med modellens beräknade sannolikhet — det är ett potentiellt spelvärde.

⚠️ Kom ihåg: Ingen modell är perfekt. Poisson-modellen tar inte hänsyn till allt (t.ex. motivationsnivå, väder, strategiska val). Använd alltid ditt eget omdöme. Spela ansvarsfullt.
