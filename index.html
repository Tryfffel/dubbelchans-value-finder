🧮 Analysmodeller

Poisson — Beräknar förväntade mål (λ) per lag och räknar sannolikheten för varje målscenario via Poisson-formeln. Formjustering ±15%.
Dixon-Coles — Poisson + korrektionsfaktor ρ=0.13 för låga scorer (0-0, 1-0, 0-1, 1-1) som Poisson systematiskt underskattar. Bättre för defensiva matcher.
Elo — Varje lag tilldelas ett Elo-betyg (1300–1700) baserat på lagnamnet. Hemmaplansfördel = +65 Elo-poäng. Enkel och robust, bra för att fånga styrketrender utan måldata.
Marknadsimplicit — Beräknar en konsensussannolikhet från alla spelbolags odds (marginjusterat). Letar sedan efter bolag som avviker uppåt = genuint värde utan eget räknande.
Value % = ((bästa odds / (1 / modellsannolikhet)) − 1) × 100

🎯 Kelly Criterion

f = (b×p − q) / b
b=odds−1, p=sannolikhet, q=1−p

Appen visar full Kelly och ½ Kelly (rekommenderat — halverar variansen).
